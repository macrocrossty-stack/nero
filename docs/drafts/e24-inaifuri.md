## 第2稿の変更点（シロ指摘：状況のわかりにくさ＋メタっぽさ）

1. **「この夜の設計」→「作戦」**（第20話で陽菜と名づけた言葉＝作中語。「設計」は作り手の言葉なので排除）
2. **スピーカー発見の一拍を追加**：鼻息の音が「ふつ、と途切れる」→「スピーカーを、見つけたんだ」。デコイがバレた瞬間が音でわかる＝状況の明確化＋ここから男が速くなる理由づけ
3. **「最大音量でやる」→「あんたがいちばんこわがってた夜に、この家がなる」**（演出用語を排除）
4. **corner の先を実装**：e24s_g（越える→暗転→三日後→MONAURAL）／e24s_hold（越えない→called の有無でNORMAL級救出 or SILENCE）。スタブ廃止
5. e24s_normal に赤い光の一行（状況の明確化）

## 分岐マップ

```
e24s ──[要:ステレオ]──> e24s_stereo ──> e24s_after ──> e25s ──┬─ c_stereo ─> STEREO
     └─ ありったけ ──> e24s_plain                              └─ else ────> NORMAL
                          ├─ c_move&c_dog ─> e24s_normal ──> e24s_after

                                       ├─ 越える ─> e24s_g ─────────────────> MONAURAL

```
- 第21話の事前通報（called）がここで効く＝「積み重ねで差が積もる」分岐方針の実装。
- 暗い結末は方針どおり：手段は書かない。選択→暗転→時間経過。
