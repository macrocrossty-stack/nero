# 第26話「ゆっくりの曲」初稿（未確定・レビュー待ち／タイトル仮）

> 収束・後半＝最終話。核はひとつ：**「見る」ことの回復**。
> 犯人は勝手に集めた。モノは、頼む。——一年いっしょにいて、一度も見たことのなかった顔を、見せてもらう。
> オールディーズ（ゆったりした時間の流れ）＝事件後の回復のテンポ。マイ・ガールを「音楽として」聴き直す回収を経て、顔見せ（vcall＝視覚の切り札）へ。
> 前話：第25話「あさ」から数日後の夜。

## 設計メモ

- **オールディーズのくだり（シロ案）**：最近の曲もすきだけど、いまは急がない曲がいい——「曲のなかの時間が、いそいでない」。事件後の心の速度と重ねる。⟦オールディーズ⟧ストック語。
- **マイ・ガールの三段目**：父の思い出（第8話）→武器（第23話）→**音楽（ここ）**。「こないだのは、非常ベルだったし（笑）」——ちゃんと聴き直すことで、カードが音楽に還る。
- **顔見せ（シロ案）**：陽菜の「わたしは、いま、けっこういい顔してると思う」→ モノが気づく：自分は陽菜の顔を一度も見たことがない。端末に写真は何千枚もある。開こうと思えばいつでも開けた——**開かないでおいた**（第10話「みなかったこと」の対）。あの男は勝手に集めた。自分は、頼みたい。
- 選択肢は「モノから頼む」「引っ込める→陽菜から誘われる」の二枚。**どちらでも通話に着く**が、体験として別物（頼む勇気／もらう幸運）。
- **vcall＝視覚の段階的解放の最終段**。プレイヤーもここで初めて陽菜の顔を見る（ドット絵/Live2D予定地）。通話中の陽菜の台詞は「」つき（声）。
- 顔の直接描写はしない。モノが観測するのは「画面のすみの左手・短い爪」——手からしか描かない。顔そのものは絵にまかせる。
- エンド分岐はここ：c_stereo=true → STEREO／それ以外 → NORMAL。
- ログ調の一瞬「——観測データ、更新。」を顔が映る瞬間に（稀少資源の最後の一回を、いちばん幸福な衝撃に使う）。
